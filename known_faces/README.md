# known_faces

Put the photos of the people you want to recognize in this folder (not included in the repository, for privacy).

Two layouts work:

```
known_faces/
├── alice.jpg            # one photo per person: the file name is the person's name
├── bob.png
└── carol/               # or one folder per person with several photos
    ├── 1.jpg
    └── 2.jpg
```

Tips: use clear, front-facing photos with one face each, and only photos of people who have agreed to be included.
